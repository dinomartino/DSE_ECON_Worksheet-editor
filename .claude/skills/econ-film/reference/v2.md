# Film v2 reference

Contracts, the review method and the pitfalls of `scripts/film2/`. The bible
(`scripts/film2/FILM.md`) holds the look, story and numbers; where code and bible disagree,
the code is right, fix the bible.

## Contracts

**Scene module** `stage/scenes/<id>.js`: `{ setup(ctx), update(ctx, t), events? }`. `t` is
scene-local seconds; `update` is pure. Helpers for one scene go in `scenes/<id>/`.

**`ctx`**: `el` (scene root), `lib`, `tl`, `W/H/fps`, `from/to/dur/window`,
`pulse(n)/beat(n)/bar(n)` (scene-local seconds), `copy` (= `COPY[id]`), `cue(id)`,
`load.clip(assetId, box, parent)`, `load.url(assetId)`, `placeClip(assetId, { at, from, rate,
dur })` (declare every clip use; the doctor checks the window is inside the clip),
`onDispose(fn)`. Assets load by registry id only. Sound: `events: [{ t, kind, label?, size? }]`
(kinds in `audio/sfxmap.mjs` `MAP` → the synthesised kit in `audio/kit/`). Footage clicks and keys
arrive through placed clips: never duplicate them.

**Type** (`lib/type.js`): `block(parent, { ...HEADLINE, ...ctx.copy.x }).show(t, { at, out })`.
`HEADLINE` 72, one line at (96, 96); `STATEMENT` 112, 2 lines; `label()` with `LABEL` 22 caps;
`DISPLAY` 160 for a rolling figure; `END_CARD`. Never type a size.

**Layout** (`lib/layout.js`): `C1` (headline over a 1728×744 card at 96,264, footage 1.2×), `C1N`
(card 1144×744 at x 680, portrait subjects), `C2` (statement left, object right, bleeds off the
bottom only: `{ ...STATEMENT, ...layout.C2.statement }`), `C3` (centred), plus `WIDE`, `SAFE`,
`AXES`, `PRINT_MIN_W` 1190.

**Camera** (`lib/camera.js`): `cam = camera(ctx, { src })`; `clip = await ctx.load.clip(id, cam.box,
cam.content)` (or `cam.image(url)`); `cam.shots([{ at, size: 'wide'|'medium'|'narrow'|'close', focus,
safe?, zoom?, move?: { to, at?, dur? }, drift?, dim? }])` returns lint problems; `cam.update(t)`;
`cam.toScreen([cssX, cssY])` places dots and callouts on footage. WIDE card at 0.62; MEDIUM the C1
card; CLOSE 2.4–3.0× full-bleed (no card, no dim, no headline). One move per shot, or a drift
≤ 3 %. `safe` = a rect that stays whole in frame. Dim ≤ 0.16, eased both ends. Doctor budget:
CLOSE ≥ 25 %, MEDIUM demo cards ≤ 35 %; a cut that keeps the shot size is a lint error.

**Re-ink** (`lib/reink.js`): after a footage proof the element leaves as vector art.
`lift(t, from, to, { at, dur, carry })`: `from` is a design rect, screen rect, element or
`{ cam, rect }` (pose the camera at the lift start first: `cam.update(at)`, take
`screenRect(...)`, then `cam.update(t)`). `carry: true` gives `.carry.apply(cam.el)`: the source
card rides along and fades over 1.5 pulses, so the piece never sits small on bare cream. Detail
after the lift: `stroke`, `hatch`, `roll` (numbers), `bars`, `wavy`. Each lift ≤ 7 pulses; add a
`pencil` event.

**Transitions** (`SCENES[].in`): `cut`; `match` (a cut whose frames share a shape); `push`;
`iris { pulses, at }` (only 12.46 and 72.92); `axis { pulses: 4, dotTo? }` (the chapter at 30.25,
51.58, 94.26; six pulses; label from `COPY.chapters[id]`; it owns x 96 and y 1008 from B−2 to B+4:
keep them clear). The engine poses the slot.

**Declarations in `timeline.mjs`** (what `tools/motion-check.mjs` exempts; a flag anywhere else is
a bug):
- `cuts`: film seconds, on pulses, of an intended hard change inside the act.
- `ui`: film seconds of a real-footage click whose response is instant (dialog opens, toggle flips).
- `holds: [[from, to]]`: a still picture is meant (a printed page being read).
- `alive: [[from, to, still?]]`: a slow drift is meant; a frame counts as still only under `still`
  (default MAD 0.02), so a frozen frame still flags. Prefer `alive` to `holds`.

They move with every retime; a stale one hides a real stall.

**Doctor**: timeline tiles 0..DURATION with cuts on the pulse grid; cues sorted and unique; assets
and grid copy current; audio long enough; clip windows; text fit; no line-end punctuation in
rendered lines; presets only; headline visible ≥ 2 s; shot budget.

## The review-panel method (5/10 to 8)

1. **Five lenses**, one read-only agent each, scored /10: story, type, motion, sync (sound),
   truth (claims against the app). Input: the mp4, 1 s contact sheets, bible, timeline, tools.
2. **Measured findings only**: `{ time, scene, severity, problem (measured), fix (file + values),
   evidence }`, ≤ 20 per round, ≤ 8 in the last. Round N+1 reviewers mark each earlier finding
   fixed / partly / not fixed with evidence, then add new ones.
3. **Round structure**: the system integrator first (shared files: type presets, layout, camera,
   re-ink, axis chapter, cues, doctor rules) so every scene agent inherits one system; then scene
   agents in parallel, each owning only its act's files and reading its findings plus the story
   lens's per-act redesigns. Scene agents **request** shared-file changes in their report (exact
   diff); the **coordinator applies timeline, cue and declaration diffs** and merges. Brief every
   agent with an explicit base SHA and the numeric targets, so they self-score on the same rules.
4. The last round is polish, not redesign. Gate: doctor 0 errors; whole-film `motion-check` 0
   stalls/jumps/flashes/weak cuts; master −16 LUFS, ≤ −1 dBTP.

## Pitfalls found in v2

- **Iris visibility leak**: a descendant left at `visibility: visible` ignores a hidden slot and
  paints into the other act. Hide slots with opacity.
- **`clip-path` erases corners**: a clip on a card cuts its rounded corners and shadow. Clip only
  during the transition, then `none`.
- **ffmpeg `-vsync` is removed**: use `-fps_mode`, or neither for constant-rate input.
- **Contact-sheet empty cells read as black frames**: fill gaps mid grey (`tools/contact.mjs`).
- **librosa tempo is wrong** (half/double, 136 BPM drifting ~0.7 s): use the verified grid and
  `tools/beatgrid.mjs`; never derive a grid from analysis.
- **ffmpeg `alimiter` delays the signal**: hits drift off their events unless compensated;
  `audio/verify.mjs` checks every impact lands within 5 ms.
- **`loudnorm` falls back to dynamic mode**: `mix.mjs` iterates gain + limiter against `ebur128`
  instead; do not use single-pass `loudnorm`.
- **Headline wrapping creates line-end commas**: the doctor reads wrapped lines; fix with `\n` or
  `maxLines`, never by rewording signed-off copy.
- **The answer clip must match the Teacher answer**: the red curve shown is the one the teacher
  copy has; shown totals equal the app panel.
- **AI and Gemini never appear on screen** around Check terms: crop to the "Check terms … free"
  row; mask the ✦ AI button and the Gemini row; no third-party names.
- **Footage clicks land 1–2 pulses after a cut** unless the clip is shifted: set `placeClip` `from`
  so the click sits on the cut, or add a `whoosh-s` cue (the kit's `air`).
- **Sound: the music leads** (FILM.md §6). The kit is synthesised and in key (D major; pitched
  sounds follow the chord in `kit/harmony.json`): tick, plip, air, glint (every draw-on; never
  pencil foley), chapter, bloom (the lift), bell (the end). At most one sound per beat; a cut on a
  strong music accent needs no sound; typing, paper and pages are silent. Change levels only via
  `SOUNDS[].rel_lu` (LU against the music at the event), never per event. A sound's design lives
  in `kit/params.mjs`; after a change run `gen.mjs`, `check.py` (venv with numpy, soundfile,
  matplotlib) and listen to `audio/kit/reel.mp3`.
- **Dims above ~0.16 grey the whole card**; **CLOSE crops cut words** (declare `safe`); **printed
  pages as thumbnails** (≥ 1190 px or crop); **still bookends** (open on a CLOSE and pull back; the
  end lockup drifts to the last frame); **small lifts on bare cream** (use `carry`).

## Other formats

v2 has **no portrait format, no spotlight cut and no second timeline**. `render.mjs --w/--h` only
rescale pixels; every scene is composed for the 1920×1080 design space, and `SCENES` is the one
timeline. A 9:16 cut needs a second composition set in `lib/layout.js` and per-scene branches; a
30 s spotlight needs a timeline selector in `timeline.mjs` first. Both are new work, not flags.
For a different film, copy `scripts/film2/` to a new folder, change `music.mjs`, its grid,
`paths.mjs` `MEDIA`, `timeline.mjs` and `COPY`, keep `lib/`, `engine.js`, `tools/`, `audio/`, write
the bible first, then clips, then scenes, then run the panel method.
